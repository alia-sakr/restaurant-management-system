# Restaurant Management System

A Java Swing desktop app for taking restaurant orders: menu items, customer details and order history, delivery status tracking, and cash or card payment. Built with object-oriented design: `Customer` and `Staff` extend `User`, with separate `Order`, `MenuItem`, `Delivery` and `Payment` classes.

**Tools:** Java, Swing, NetBeans

## Run it
Open this folder as a project in Apache NetBeans and run `RestaurantGUI`.
